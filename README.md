# D3DDD master website (d3ddd.com)

A static multi-page site combining the owner's two sites: site-a (Shoaib Designer marble content and process) and site-b (D3DDD editorial design). It also has a Supabase client portal (projects, files, profile). Online payments were removed at the owner's request. **Nothing is deployed, and no accounts have been created.**

## Pages
index, services, marble, website-design, about, contact (enquiry form), thank-you, login, signup, dashboard.
- Pages are generated by `build.py`. Edit content there, then run `python3 build.py`.
- Each page has SEO basics (title, description, canonical, Open Graph). `sitemap.xml` and `robots.txt` are included, and the home page has LocalBusiness JSON-LD.
- Config is in `assets/config.js`.

## What the owner must supply or set up
1. **Supabase (client portal).** Create a free project at supabase.com and run `supabase/schema.sql` in the SQL Editor. That creates the tables, RLS, a private `client-files` bucket, and a profile trigger. Then:
   - Put the Project URL and anon key into `SUPABASE_URL` and `SUPABASE_ANON_KEY`.
   - Under Auth > URL Configuration, set Site URL to https://d3ddd.com.
   - Sign up on the site, then run the commented `update ... is_admin = true` line for your own email.
   - Add projects for clients from the Supabase Table Editor. Clients can only read their own rows, and only admins can write projects.
   - Until the keys are filled in, the portal runs in **DEMO mode**: data lives in browser localStorage, with a DEMO banner and sample rows.
4. **Enquiry form:** works without a server. When a visitor submits it, their email app opens with a message to info@d3ddd.com already filled in, so it runs fine on GitHub Pages. The client portal links are hidden until Supabase is set up. Payments go through https://paypal.me/imshoi.
5. **Images:** `assets/img/drawings/*.svg` are original hand-drawn SVG line drawings (sofa, chair, table, bed, kitchen, vanity, staircase, elevation, tiles, cladding). They are generic illustrations, not D3DDD project work.
6. **Content to confirm:** business address or area, trade licence name, prices for the other services.
7. **Hosting/DNS:** see ../DEPLOY.md. Get approval before deploying or changing DNS.
8. **Legal:** add a privacy policy, since the portal stores client data.

## Bilingual site and SEO (added)
- Arabic pages live in `/ar/`, laid out right-to-left with the Tajawal font. Every page has a language switcher, hreflang tags (en-AE, ar-AE, x-default) and canonical links. `sitemap.xml` lists the alternate language URLs.
- Content lives in `content.py`. `build.py` holds the layout, SEO tags and schema. The client portal pages are in `portal_pages.py` and are English only. Rebuild with `python3 build.py`.
- Schema markup is in JSON-LD: ProfessionalService/LocalBusiness (city-level address only, with no street, ratings or reviews), Service with an AED 2,000 Offer for the website package, FAQPage on the home page, BreadcrumbList, WebSite and ContactPage. Each page also has Open Graph and Twitter tags (`assets/img/og-image.png`) and a geo meta tag (AE-DU).
- **Owner SEO to-dos:**
  1. After going live, verify d3ddd.com in Google Search Console (DNS TXT record at GoDaddy) and submit https://d3ddd.com/sitemap.xml. Do the same in Bing Webmaster Tools.
  2. Create or claim a Google Business Profile with category "Drafting service" or "Architectural designer". If there is no public office, set it up as a service-area business covering Dubai, Abu Dhabi and Sharjah. Use the same name, email and website as the site.
  3. Ask real clients for Google reviews. Do not add review or rating markup until reviews actually exist.
  4. Add social profile URLs to `sameAs` in `build.py`, and add the street address only if you want it shown publicly.
  5. Replace the line drawings with your own real drawings and renders over time, using descriptive alt text.
